# Weather App 🌤️

## Project Description
Developed a Weather App using HTML, CSS, and JavaScript with the OpenWeatherMap API. It fetches weather data using the Fetch API and displays temperature, humidity, and weather conditions based on the entered city name.

## Features
- Search weather by city name.
- Displays current temperature.
- Shows humidity percentage.
- Displays weather conditions.
- Clean and simple user interface.

## Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeatherMap API
- Fetch API
- JSON

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Add your OpenWeatherMap API key in `script.js`.
4. Open `index.html` in your browser.
5. Enter a city name and click Search.

## Learning Outcomes
- Understanding API integration.
- Using Fetch API to retrieve data.
- Parsing JSON responses.
- Working with DOM manipulation.
- Handling asynchronous JavaScript.
